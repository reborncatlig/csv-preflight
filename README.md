# CSV 交付前检查器

免费原创工具演示，用于展示独立创作与浏览器本地处理能力。尚未验证付费需求；没有付费商品、售价、付费权益或交付承诺。当前没有附带开源许可证，不以“开源”宣传。

设计为可直接双击 `index.html` 离线使用；本轮实际通过的是本地 HTTP 界面测试，`file://` 直接打开受内置浏览器安全策略限制，未完成实测。不需要安装依赖或启动服务。仅用经典脚本加载本地文件，无 CDN、上传、远程字体、分析追踪、本地存储或账号功能。粘贴数据、选择合成样例、检查、清空、下载 JSON 结果均可在本地完成。页面页尾的[创作主页](https://afdian.com/a/reborncatlig)为可选支持入口，使用本工具不要求支持。

## 范围

- 输入为 UTF-8 CSV 文本，逗号分隔，第一条逻辑记录为表头；最多 500 KiB（512,000 字节）。不支持文件导入、XLSX、PDF、制表符分隔或自动编码识别。
- 支持引号内逗号、转义双引号、字段内换行、BOM、CRLF。字段内 CRLF/CR 换行统一为 LF；原始物理行号仍保留。引号必须位于字段开头，闭合后只允许逗号或换行；畸形引号明确报错。
- 检查列数不齐、空或重复表头、完全空数据记录。表头比较去除两端空白并区分大小写；不会自动修正。空数据记录保留，单个末尾换行不会虚构额外记录。
- 检查忽略前导空白后以 `= + - @` 开头的文本；仅提示潜在电子表格公式解释风险。负数可能合法，提示不是恶意判断；未提示也不表示已安全。此工具不做对账、金额匹配或完整安全审计。
- 记录号包含表头；原文行号、字符号及列号从 1 开始，字段位置指向原文起点（包括开头引号）。BOM 不计入字符号。预览使用 `textContent`，用户文本不作为 HTML 解析。
- 页面最多展示前 200 条提示、表头和前 30 条数据记录、前 30 列；检查覆盖完整输入。JSON 下载含完整解析数据与检查结果，请自行妥善保管。

## 验证

在本目录运行 `node --test checker.test.cjs`，使用 Node 内置测试，不需要第三方依赖。测试覆盖解析、原始位置、空行、风险提示、XSS 文本保留和输入大小限制。浏览器界面与真实平台接入仍需另外验收，不能以单元测试代替平台商业或收款验证。

文件：`index.html` 页面，`styles.css` 样式，`checker.js` 纯检查逻辑（浏览器全局 / CommonJS），`app.js` 页面交互，`checker.test.cjs` 测试。
